# Security

Canary is an open-source, read-only monitoring tool for public Pons V2 contract data on Robinhood Chain.

The public site at https://usecanary.watch does not require an account, wallet connection, payment, or credential entry. It does not expose transaction execution.

## Reporting a security issue

Please open a GitHub issue at https://github.com/Gipppp121/canary/issues with a minimal reproduction. Do not include secrets or private credentials in reports.

For the deployed site, the security contact is also published at:

https://usecanary.watch/.well-known/security.txt
