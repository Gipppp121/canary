# Canary v0.4 local prep

This package is intentionally local-only. Applying it does not run git commit, git push, SSH, systemctl, or any VPS command.

## What v0.4 changes

### 1. Graduated-pool deterministic rules

Canary v0.3 already handled curve reserve loss, deployer balance movement, fee movement, dead volume, serial deployers, and phase changes. v0.4 adds explicit post-graduation rules:

- `pool-liquidity-drop` - active Uniswap v4 liquidity fell materially between sweeps
- `pool-price-move` - display price moved materially between sweeps (WATCH context only)
- `pool-token-fees-moved` - pending token-denominated hook fees decreased
- `pool-swap-burst` - recent observed swap count jumped between sweeps

These remain deterministic rules. They do not place trades and do not claim intent.

### 2. RPC fallback

Set optional backup RPC endpoints:

```env
RPC_FALLBACK_URLS=https://backup-one.example,https://backup-two.example
```

The reader remembers the last working endpoint and retries the remaining configured readers when a read fails.

### 3. Public-board control hardening

The live desk remains readable through a reverse proxy, but `WATCH TOKEN` and `STOP` are no longer implicitly trusted just because Nginx talks to Canary over 127.0.0.1.

For a public/proxied board, configure:

```env
CANARY_CONTROL_TOKEN=use-a-long-random-value
```

Then save the same value with the board's `CONTROL KEY` button. The browser stores it in localStorage and sends it only in the `x-canary-control` header for watcher-control POST requests.

Without a control token, only a direct localhost browser request can start/stop watchers.

### 4. Version / repo polish

The local package bumps visible product/version metadata to Canary v0.4 and adds tests for the new pool rules, fallback reader, and control authorization.

## Apply later

Extract this package into the Canary repo root and run:

```bat
powershell -ExecutionPolicy Bypass -File .\apply-canary-v04-local.ps1
```

The script creates backups, applies the local files, runs typecheck, all tests, and build, and restores the previous files automatically if validation fails.

It never uploads anything.
