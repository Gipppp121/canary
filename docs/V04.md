# Canary v0.4

Canary v0.4 strengthens post-buy monitoring for Pons V2 tokens on Robinhood Chain while keeping the project fully read-only.

## What changed

### Graduated-pool signals

v0.4 adds deterministic monitoring for:

- `pool-liquidity-drop`
- `pool-price-move`
- `pool-token-fees-moved`
- `pool-swap-burst`

These signals compare consecutive snapshots and surface meaningful state changes without placing trades or inferring intent.

### RPC fallback

Canary can now use optional backup RPC endpoints through:

```env
RPC_FALLBACK_URLS=https://backup-one.example,https://backup-two.example
```

If the preferred reader fails, Canary tries the remaining configured endpoints and remembers the last working one.

### Public-board control hardening

The live board can stay publicly readable while watcher start/stop actions remain protected.

Configure:

```env
CANARY_CONTROL_TOKEN=use-a-long-random-value
```

The browser sends the control key only for watcher-control POST requests.

Without a control token, only direct localhost control is accepted.

### Read-only guarantee

Canary v0.4 still has:

- no signer
- no private key
- no wallet client
- no transaction builder
- no send path

It watches, remembers, compares, and alerts.
